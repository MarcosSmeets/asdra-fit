# Concept sheets das linhas evolutivas

Geradas com o modo built-in do skill `imagegen`, usando
`apps/mobile/assets/adaris/sheets/adari-action-atlas-v2.png` como referencia de
estilo e identidade.

- `terravok-concept-v1.png`: Brontu, Brontar, Bronterra e Asterhorn.
- `lumora-concept-v1.png`: Velune, Velair, Velustra e Stridara.
- `solivar-concept-v1.png`: Myrin, Myrix, Myrandel e Solvyr.

Objetivo: aprovar silhueta, materiais, paleta e progressao. Nao recortar estas
folhas diretamente para o runtime. A arte final deve ser refeita no atlas 8x1
de `assets-source/adaris/README.md`.

Os prompts finais usados estao em `prompts.md`; as restricoes por forma estao
consolidadas em `docs/ADARI_EVOLUTION_ART_DIRECTION.md`.
